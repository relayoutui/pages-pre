Justify

Class: rl-justify-*

The justify utility places the elements of a layout along its main axis, the direction they flow: horizontally in a row, vertically in a column.

Values

Section titled “Values”
Class Places the elements
rl-justify-start at the start of the main axis
rl-justify-center in the middle of it
rl-justify-end at the end of it
rl-justify-between the first at the start and the last at the end, with the free space shared between the elements
Layout Main axis Default Shows
Column Vertical start Only when the column is taller than its elements
Row Horizontal start On each wrapped line; there is no free space next to an element with rl-width-fill
Grid Never: the cells share the whole width
Frame Horizontal space-around Centers one element, and spaces several

Align places the elements across the main axis.

Section titled “Justify with column”

Justify with grid

Section titled “Justify with grid”

Justify does nothing in a grid. The cells share the whole width, so there is no free space to place them in. To place an element within its cell, limit its width with rl-width-* and center it with rl-center-self, and use rl-align-* for the vertical position.

A grid has one set of columns for all its rows, so a last row that isn’t full sits in the first columns, with or without justify. To center or right-align a last row, use a row that wraps, with a width on each element: a row places each of its lines on its own. Five elements 150px wide in a row 500px wide make a line of three and a line of two. The line of two starts at 100px and 250px with rl-justify-center, and at 200px and 350px with rl-justify-end, where in a grid 500px wide with three columns it starts at 0 and 167px, whatever the justify. The elements don’t widen to share the line, so each needs its width.
