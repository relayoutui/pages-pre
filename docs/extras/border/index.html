Border

Classes: rl-border, rl-border-top, rl-border-bottom, rl-border-start, rl-border-end

The border utility adds a border around an element, drawn from --rl-border-default: a solid 1px line, hsl(0, 0%, 50%), on all four sides. That gray is a placeholder that keeps a boundary in sight until you set your own (Customizing). The border is inside the element’s width (box-sizing: border-box). It goes on any element, a layout or an item inside one.

rl-border also rounds the corners by --rl-radius-default, which is 0, so the corners are square until you set it or add rl-radius-*.

One side

Section titled “One side”

rl-border-top, rl-border-bottom, rl-border-start and rl-border-end draw the same line on one side, with no radius. Start and end follow the reading direction, as rl-text-start does: in a page that reads from right to left, start is the right side. Two classes draw two sides, such as rl-border-top rl-border-bottom.

A side border separates elements of the same kind, such as the items of a list or a sidebar from its content, with no element of its own. A divider is an element between two others, and has to be a direct child of a layout: use it where the line isn’t part of either side.
