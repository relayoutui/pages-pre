Installation

You can load Relayout from a CDN, as a local CSS file in your project, or with npm and a tool such as Sass that embeds Relayout in your own CSS.

Relayout is before 1.0, so a release can rename classes. Each example below names a version: use the one your project was written for, and move to a newer one on purpose. The changelog lists the changes.

Browsers

Section titled “Browsers”

Relayout supports the current versions of Chrome, Edge, Firefox and Safari. Its tests run in Chrome, Firefox and WebKit, the engine of Safari, on every change.

Local installation

Section titled “Local installation”

Download the CSS file from the CDN, https://cdn.jsdelivr.net/npm/@relayoutui/relayout@0.8.0/dist/css/relayout.css, and link it in your project. Include it in the build.

Web components

Section titled “Web components”

rl-div, the element for markup inside a shadow root, is a script that you load beside the CSS. From the CDN, relayout.bundle.js is one file with everything it needs, Lit included. With npm, the package depends on Lit and npm installs it with the package, so your bundler includes one copy of Lit for your code and for Relayout. Web components has the code to load it.

npm installation

Section titled “npm installation”

To embed Relayout in your own CSS, or to import it from your code, use npm.

If your project does not have a package.json file, you can create one using npm init.

Embedding the CSS with Sass needs Relayout only when you build, so install it as a dev dependency.

A project that imports rl-div, whose script runs in the browser, installs it as a dependency instead: npm install @relayoutui/relayout.
