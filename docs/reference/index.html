Reference

Every class and custom property of relayout.css 0.8.0, the version the previews on these pages run. This page is built from that file when the docs are built, so it lists what ships, and a class that isn’t here doesn’t exist.

A class is listed with the rules it sets, written as in the stylesheet, and the custom properties those rules read. A rule for a child, such as rl-width-fill in a row, shows its selector. The page linked under each heading says when to use its classes. The one element, rl-div, takes the same classes.

A custom property set on :root changes the whole page, and one set on an element changes what is inside it.

There are 144 classes and 51 custom properties.
